# Grudge

*The level never forgets. Neither do you.*

A tiny troll platformer in a single HTML file. 10 phases of 5 levels, plus a bonus phase that remembers where you jumped. When you die on spikes you leave a solid grave stone behind, and you can stand on it next time.

**Play:** https://s4mu3ldemolidor.github.io/grudge/

## Controls

| Action  | Keyboard            | Gamepad      |
|---------|---------------------|--------------|
| Move    | Arrows / WASD       | D-pad, stick |
| Jump    | Space / Up / W / Z  | A            |
| Restart | R                   | X / Y        |
| Menu    | Esc                 | B / Select   |
| Sound   | M                   |              |

On phones, on-screen buttons appear automatically.

## Run it locally

Open `index.html` in a browser. There's nothing to install or build.
